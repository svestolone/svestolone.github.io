GitHub Pages & Production Setup

Hosting, EmailJS automation, and multi-device database notes

1 Deploy on GitHub Pages

  1. Create a new GitHub repository (e.g., gathering-initiatives).
  2. Upload this file as index.html in the root branch.
  3. Open Settings → Pages, select main branch as the source, and click Save.

2 Configure Automated EmailJS Templates

Click the Settings gear icon in the top header and enter your EmailJS Public Key, Service ID, and Template ID. In your EmailJS dashboard template, set the "To Email" field to {{to_email}} and include these variables in your email body: 

Recipient: {{to_name}} <{{to_email}}>
Subject:   {{subject}}
Topic:     {{topic}}
Date/Time: {{date_time}}
Venue:     {{venue}}

{{message}}

3 Production Multi-Device Security Recommendation

Out of the box, this app hashes passwords using Web Crypto SHA-256 and stores records in localStorage for zero-server testing on GitHub Pages. For live multi-device production across the internet, connect Supabase Auth + PostgreSQL or Firebase Auth + Firestore (with Row-Level Security so user emails remain hidden from public queries).
