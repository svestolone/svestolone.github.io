GitHub & Live Email Deployment Guide

Zero-build single-file architecture ready for GitHub Pages

1 Host on GitHub Pages in 60 Seconds

  1. Create a new public repository on GitHub named gathering-initiatives.
  2. Save this application file as index.html in the root of your repository.
  3. Go to Settings → Pages, select the main branch, and click Save.

2 Connect Real Outbound Emails (EmailJS)

This app includes a built-in EmailService module. To send real emails to organizers and all 8 participants without a backend server, sign up for a free EmailJS account and paste your keys into EMAILJS_CONFIG at the top of the script: 

const EMAILJS_CONFIG = {
  enabled: true, // Set to true once keys are added
  serviceId: 'service_your_id',
  organizerTemplateId: 'template_member_joined',
  groupFullTemplateId: 'template_circle_closed_8',
  publicKey: 'your_emailjs_public_key'
};

3 Multi-User Cloud Database (Optional Upgrade)

Currently, gatherings persist in browser storage for instant standalone GitHub Pages usage. To share live registrations across different devices globally, connect Firebase Firestore or Supabase inside the StorageAdapter module.
